Responses

Your RSVPs live in the Google Sheet attached to your form. Nothing is stored on this website — the dashboard reads the sheet in your browser and keeps nothing of its own.

Keep it up to date automatically

  1. In the Sheet: File → Share → Publish to web.
  2. Choose the responses sheet, and the format Comma-separated values (.csv).
  3. Press Publish, then copy the link it gives you and paste it here.

This link is saved in this browser only. It is never added to the website's code, so nobody reading the site's source can find it. Anyone who does get the link can read the sheet without a password, so treat it like a key — and you can stop it at any time with Publish to web → Stop publishing.

Or load a file by hand

  1. In the Sheet: File → Download → Comma Separated Values (.csv).
  2. Drop that file below, or open it in a text editor and paste the contents.
